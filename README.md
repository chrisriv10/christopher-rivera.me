## Features

- **Animated space background** — Star field with nebulae and shooting stars
- **Scroll-directed particle sphere** — Adaptive Three.js visual that connects the Hero and About sections
- **Premium motion system** — Lenis smooth scrolling synchronized with GSAP and ScrollTrigger
- **Dark theme** — Clean, minimal design with blue accent colors
- **Multi-language** — English / Spanish toggle
- **Responsive design** — Works on all screen sizes
- **SEO optimized** — Open Graph, Twitter Cards, Schema.org JSON-LD, sitemap.xml, robots.txt
